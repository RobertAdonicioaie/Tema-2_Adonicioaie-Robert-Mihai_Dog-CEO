# Dog Explorer - Proiect API

Acest proiect este o aplicație web simplă care interacționează cu [Dog CEO API](https://dog.ceo/dog-api/) pentru a afișa imagini aleatorii cu câini.

## Funcționalități
- **Afișare Imagine:** Încarcă o imagine random la apăsarea unui buton.
- **Istoric:** Salvează rasele de câini generate într-un tabel, extrăgând numele rasei din URL-ul imaginii.
- **Interfață:** Design modern și responsive.

## Cum se folosește
1. Deschide fișierul `index.html` în browser.
2. Apasă pe butonul "Adu un alt câine!".
3. Consultă tabelul de istoric pentru detalii despre imaginile generate.

## Tehnologii
- HTML5, CSS3, JavaScript (Vanilla)
- Fetch API (Async/Await)
